# Per-Project WCS 180°-Flip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per-Project Toggle "Flip 180°" in der Labels-Panel-Header. Wenn aktiv, dreht der Catalog-Overlay-Renderer den FITS-WCS um 180° um CRPIX, bevor er Catalog-Objekte projiziert. Default off, persistiert in `manifest.json`. Behebt den point-mirrored-Labels-Bug (z. B. leo4) ohne Plate-Solving.

**Architecture:** Neues Pydantic-Field `Project.wcs_flip_180: bool`. Neuer Helper `apply_wcs_flip(wcs)` in `src/renderer/wcs.py`. Single Call-Site in `_prepare_catalog_overlay_data` (`render_layout.py`). Eine Checkbox im `_build_labels_panel` mit `on_change` → mutate + `_persist_project` + Re-render des Overlays.

**Tech Stack:** Pydantic v2 (`BaseModel.Field`), `astropy.wcs.WCS`, NiceGUI `ui.checkbox`, pytest.

**Spec:** [docs/superpowers/specs/2026-06-06-wcs-180-flip-design.md](../specs/2026-06-06-wcs-180-flip-design.md).
**Analyse:** [docs/wcs-pierside-analysis.md](../../wcs-pierside-analysis.md).

def test_apply_wcs_flip_is_180deg_rotation_around_crpix():
    """A pixel offset from CRPIX maps to its point-mirror after flip."""
    from src.renderer.wcs import apply_wcs_flip
    wcs = build_wcs(
        center_ra_deg=180.0, center_dec_deg=45.0,
        frame_dims=(1000, 800), pixel_scale_arcsec=1.0,
        north_angle_deg=10.0,
    )
    ra, dec = wcs.pixel_to_world_values(700, 200)
    apply_wcs_flip(wcs)
    x, y = wcs.world_to_pixel_values(ra, dec)
    # CRPIX in 0-indexed = (499.5, 399.5); 700→299, 200→599 (Spiegelung)
    cx, cy = wcs.wcs.crpix[0] - 1, wcs.wcs.crpix[1] - 1
    assert x == pytest.approx(2 * cx - 700, abs=1.0)
    assert y == pytest.approx(2 * cy - 200, abs=1.0)


def test_apply_wcs_flip_idempotent_twice_restores():
    """Two flips return to the original projection."""
    from src.renderer.wcs import apply_wcs_flip
    wcs = build_wcs(
        center_ra_deg=180.0, center_dec_deg=45.0,
        frame_dims=(1000, 800), pixel_scale_arcsec=1.0,
        north_angle_deg=10.0,
    )
    x0, y0 = wcs.world_to_pixel_values(180.05, 45.03)
    apply_wcs_flip(wcs)
    apply_wcs_flip(wcs)
    x1, y1 = wcs.world_to_pixel_values(180.05, 45.03)
    assert x1 == pytest.approx(x0, abs=1e-6)
    assert y1 == pytest.approx(y0, abs=1e-6)

```python
def apply_wcs_flip(wcs: WCS) -> WCS:
    """Negate CD/PC matrix → 180° rotation around CRPIX.

    Workaround for capture-tool bugs where the meridian-flip pierside
    is reflected in PIERSIDE but not in CROTA2, leaving Catalog labels
    point-mirrored through the frame centre. User toggles this per
    project; see docs/wcs-pierside-analysis.md for the full picture.

    Mutates ``wcs`` in place and returns it for chaining.
    """
    if wcs.wcs.has_cd():
        wcs.wcs.cd = -wcs.wcs.cd
    else:
        wcs.wcs.pc = -wcs.wcs.get_pc()
    return wcs
```
